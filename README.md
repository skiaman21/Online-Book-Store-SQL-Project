# 📚 Online Book Store SQL Project

## 📖 Project Overview

This project demonstrates the design and implementation of an **Online Book Store Database** using **PostgreSQL**. It includes database schema creation, data import from CSV files, and SQL queries to analyze bookstore data and generate business insights.

The project covers fundamental and intermediate SQL concepts, making it a great practice project for aspiring **Data Analysts** and **Database Developers**.

- PostgreSQL
- SQL

## 🗄️ Database Tables

### Books
Stores information about books available in the store.

### Customers
Stores customer details.

### Orders
Stores customer purchase records.

## 📈 SQL Queries Included

### Basic Queries

- Retrieve books by genre
- Find books published after a specific year
- List customers from a particular country
- Display orders within a date range
- Calculate total stock available
- Find the most expensive book
- Retrieve books with the lowest stock
- Calculate total revenue

### Advanced Queries

- Total books sold by genre
- Average price of Fantasy books
- Customers with multiple orders
- Most frequently ordered book
- Top 3 most expensive Fantasy books
- Total quantity sold by each author
- Cities where customers spent more than $30
- Highest spending customer
- Remaining stock after fulfilling all orders

---

## 🚀 How to Run the Project

1. Create a PostgreSQL database.
2. Execute `schema.sql` to create the tables.
3. Update the CSV file paths in `data.sql` according to your system.
4. Execute `data.sql` to import the data.
5. Run `queries.sql` to execute the SQL queries.
